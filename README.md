# 中3英単語クイズ

中学3年生レベルの英単語を4択で練習できる、ブラウザだけで動く小さなクイズアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 表示された英単語の意味を4択から選びます。
3. 間違えた単語は復習リストに追加されます。

## 機能

- 中3レベルの英単語10問
- 4択クイズ
- 正誤判定と例文表示
- スコアと進捗表示
- 間違えた単語の復習リスト

## ファイル構成

- `index.html`: アプリの画面構造
- `styles.css`: 見た目とレスポンシブ対応
- `script.js`: クイズの出題、採点、復習リストの処理
